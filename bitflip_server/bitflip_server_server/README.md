# Bitflip Serverpod server

This package hosts Bitflip's typed mint API, wallet-signature authorization, Bubblegum compressed-NFT orchestration, canonical metadata and SVG art, and the production Flutter website.

From the repository root, `devenv shell -- server:start` launches the backend, embedded development database, migrations, and Flutter app together. Deployment configuration and required managed secrets are documented in the repository [readme](../../readme.md).
